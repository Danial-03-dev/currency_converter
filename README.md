# 🇵🇰 Pak Rupee Converter

**Pak Rupee Converter** is a simple and lightweight currency converter app built with **Flutter**.  
It converts selected international currencies **directly into Pakistani Rupee (PKR)**.

This project was created as a **portfolio/demo app** to showcase clean UI, API integration, and state management in Flutter.

---

## ✨ Features

- 🔁 Convert **foreign currencies → PKR only**
- 🌍 Supports major international & regional currencies
- ⚡ Fast and lightweight
- 📱 Responsive UI (Web, Android, Windows)
- 🧠 Clean state management using Provider
- 🌐 Live exchange rates via HTTP API

## 💱 Supported Currencies

The app currently supports conversion from the following currencies **to Pakistani Rupee (PKR)**:

- USD — US Dollar  
- EUR — Euro  
- GBP — British Pound  
- SAR — Saudi Riyal  
- AED — UAE Dirham  
- CNY — Chinese Yuan  
- JPY — Japanese Yen  
- CAD — Canadian Dollar  
- AUD — Australian Dollar  
- CHF — Swiss Franc  
- INR — Indian Rupee  
- AFN — Afghan Afghani  
- IRR — Iranian Rial  
- TRY — Turkish Lira  
- IQD — Iraqi Dinar  
- QAR — Qatari Riyal  
- KWD — Kuwaiti Dinar  
- OMR — Omani Rial  
- BHD — Bahraini Dinar  
- JOD — Jordanian Dinar  

> 🔒 Conversion direction is **always to PKR** by design.

## 🛠️ Tech Stack

- **Flutter (SDK ^3.8.1)**
- **Dart**
- **Provider** – state management
- **HTTP** – API calls
- **Intl** – number & currency formatting
- **Dropdown Search** – currency selection
